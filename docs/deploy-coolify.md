# نشر منصة الجودة على Coolify (quality.ymmm.io)

دليل مختصر لنشر المنصة على سيرفر Coolify، مع الدخول بالبريد وكلمة المرور واستعادتها بالبريد.

## المتطلبات
- سيرفر عليه Coolify، ودومين يشير إليه (سجل `A` للاسم `*` إلى عنوان السيرفر).
- مستودع GitHub `yousefm1425/aqap` (خاص).
- حساب بريد صادر (Brevo مجاني) — يمكن تأجيله، وتعمل المنصة بدونه مع نسخ رابط التفعيل يدوياً.

## 1) ربط GitHub بـ Coolify (مرة واحدة)
1. Coolify ← **Sources** ← **+ Add** ← **GitHub App**.
2. اتبع المعالج: ينقلك إلى GitHub لإنشاء التطبيق ثم **Install** — اختر **Only select repositories** ثم `aqap`.

## 2) إنشاء التطبيق
1. **Projects** ← المشروع ← **+ New** ← **Private Repository (with GitHub App)** ← اختر `aqap`.
2. **Branch:** `main` — **Build Pack:** `Docker Compose`.
3. **Docker Compose Location:** `/docker-compose.coolify.yml` ثم **Continue**.

## 3) الدومين
في صفحة التطبيق، عند الخدمة **api** ← **Domains**:
```
https://quality.ymmm.io:8000
```
الرقم 8000 منفذ الحاوية الداخلي؛ المستخدم يفتح `https://quality.ymmm.io` فقط. **Save**.

## 4) المتغيرات (Environment Variables)
تولّد Coolify تلقائياً: كلمة مرور قاعدة البيانات واسم مستخدمها والمفتاح السري (`SERVICE_*`) — لا تغيّرها.

| المتغير | القيمة |
|---|---|
| `AQAP_PUBLIC_URL` | `https://quality.ymmm.io` |
| `AQAP_SMTP_USER` | من Brevo (SMTP login) |
| `AQAP_SMTP_PASSWORD` | من Brevo (SMTP key) — فعّل **Is Secret** |
| `AQAP_MAIL_FROM` | بريد مرسل موثَّق في Brevo، مثل `no-reply@ymmm.io` |

اترك متغيرات البريد فارغة إن لم تجهّز Brevo بعد.

## 5) النشر
اضغط **Deploy**. أول بناء يأخذ 5–10 دقائق (يثبّت LibreOffice للتصدير الرسمي). عند النجاح تكون الخدمات `api` و`db` و`backup` بحالة **Running (healthy)**.

## 6) إنشاء حساب المدير الأول
Coolify ← التطبيق ← **Terminal** ← اختر الحاوية **api** ← نفّذ:
```
python scripts/create_admin.py --email بريدك@example.com --name "اسمك"
```
- إن كان البريد مهيأً يصلك رابط التفعيل؛ وإلا يُطبع الرابط في الطرفية. افتحه وعيّن كلمة المرور (صالح 72 ساعة ولمرة واحدة).
- بعدها أضف المستخدمين من صفحة **المستخدمون**؛ يصل كل مستخدم رابط تعيين كلمة المرور (أو تنسخه له إن لم يكن البريد مهيأً).

## 7) بيانات الكلية الأساسية (مرة واحدة)
في طرفية الحاوية **api**:
```
python scripts/setup_college.py
```
ينشئ المعايير الرسمية (48 متطلباً بنصوصها الرسمية)، وأقسام الكلية الستة، ودورة «التقييم الذاتي 1447هـ» مفتوحة مع تقديرات كل قسم — دون مستخدمين أو بيانات تجريبية. آمن للتكرار.

## الأمان
- `AQAP_ENV=prod`: الدخول التجريبي بالبريد وحده معطّل، والمنصة ترفض العمل بمفتاح سري ضعيف.
- كلمات المرور مجزأة بـ scrypt في جدول مستقل خارج سجل التدقيق؛ 5 محاولات خاطئة توقف الدخول 15 دقيقة.
- روابط التفعيل والاستعادة لمرة واحدة ومحدودة المدة، ولا يُحفظ في القاعدة إلا بصمتها.
- تغيير كلمة المرور أو تعيينها يُنهي كل الجلسات السابقة.
- حد محاولات لكل عنوان IP: 20 دخولاً و5 طلبات استعادة كل 5 دقائق.
- ترويسات أمان المتصفح: منع التضمين في مواقع أخرى، HSTS (فرض HTTPS سنة)، سياسة محتوى (CSP) لا تسمح إلا بسكربتات المنصة.
- تنزيل الملفات برابط موقّع صالح 5 دقائق يُصدَر بعد التحقق من الصلاحية، ويُنزَّل كمرفق دائماً.
- صفحات توثيق الواجهة البرمجية (/docs) مغلقة في الإنتاج.

## النسخ الاحتياطي
- خدمة `backup`: نسخة يومية 2:00 فجراً (بتوقيت الرياض)، تحتفظ بآخر 7 أيام و4 أسابيع و6 أشهر داخل وحدة التخزين `backups`.
- مع النسخ الأسبوعي للسيرفر من Hostinger. ويُستحسن لاحقاً نسخ خارج السيرفر (S3).

## التحديث
كل دفع إلى `main` ثم **Redeploy** (أو فعّل **Auto Deploy**). ترحيلات القاعدة تُطبَّق تلقائياً عند التشغيل (`scripts/init_db.py`).
